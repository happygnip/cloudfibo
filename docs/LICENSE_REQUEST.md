# License 申请说明

CloudFibo 安装包可免费下载和部署，产品功能通过离线 License 授权。License 与安装实例指纹绑定，并包含有效期、产品版本、功能范围和资源配额等信息。

## 申请流程

1. 完成 CloudFibo 部署并登录平台。
2. 打开“系统管理 → 许可证”，复制平台指纹。
3. 发送申请邮件至 `postmaster@cloudfibo.com`，邮件主题使用：`CloudFibo License 申请 - <公司或团队名称>`。
4. 审核完成后，CloudFibo 团队将通过邮件返回签名的 `.lic` 文件。
5. 在许可证页面导入文件并确认状态、有效期和授权范围。


## 安全提醒

- 平台指纹和联系人信息只通过邮件提交，不要发布到 GitHub Issue 或 Discussion。
- 不要发送服务器密码、云账号密钥、数据库凭据、Token、私钥或生产配置文件。
- License 文件不包含 CloudFibo 的签发私钥；请勿转发或公开收到的 License 文件。
- 重新安装或重建平台身份后，平台指纹可能变化，需要重新申请。

## 离线环境

License 校验在本地完成，正常使用不要求生产环境持续访问外部授权服务。到期续期时，按相同流程提交当前平台指纹和续期需求即可。
